# Maria Katherine's First Birthday & Dedication

Place only the photos approved for the public site in this folder.

Use sequential filenames:

`maria-katherine-001.jpg`
`maria-katherine-002.jpg`
`maria-katherine-003.jpg`

The event is represented by the folder name, so individual filenames do not need
extra dates, locations, or private details. Keep original and private photos
outside `public/`; anything in this directory can be served by the website.
